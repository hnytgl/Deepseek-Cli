# Security Policy

## Reporting a Vulnerability

Do not open a public issue for vulnerabilities that expose credentials, allow
workspace escape, bypass command policy, or enable unintended command
execution.

Use GitHub private vulnerability reporting when available. If that channel is
unavailable, email [hnytgl@163.com](mailto:hnytgl@163.com) with:

- affected version or commit
- impact and prerequisites
- minimal reproduction steps
- suggested mitigation, if known

Do not include live API keys, unrelated personal data, or data obtained from
systems without explicit authorization.

Reports are acknowledged on a best-effort basis. Please allow time for a fix
before publishing technical details.
